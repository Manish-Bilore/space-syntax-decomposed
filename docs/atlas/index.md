# Map atlas

Generated by `scripts/12_atlas.py` from the Phase 0–1 outputs. Maps show interior streets; classes are quintiles within each panel (ranks rather than raw values are comparable between panels and cities). Divergence maps show the percentile-rank difference between two measures: thin grey where they agree within 10 points. Street data © OpenStreetMap contributors (ODbL).
